# Retail product discovery: exact-variant pickup clarity

An independent undergraduate product management portfolio project by Andre Taylor, exploring how shoppers identify running shoes that meet their size, budget and chosen-store pickup requirements. Research across DICK'S Sporting Goods, Academy Sports + Outdoors and REI led to a bounded desktop concept inspired by an Academy listing-to-product eligibility concern. This is not an official retailer initiative.

The current outcome is a working three-product local prototype, a revised Product Requirements Document (PRD), functional checks and internal design review. All prototype availability is simulated. Customer comprehension, production feasibility and business impact remain unvalidated.

## Open the prototype

Download or clone the repository, then open `prototype/index.html` directly in Chrome by double-clicking it or using Chrome's Ctrl+O. Keep its local CSS and JavaScript files together. No installation, build or server is needed. The demo has no live inventory, ordering or accounts.

With Any color selected, results picture a confirmed qualifying variant. An explicit color is respected; confirmed non-matches are excluded and uncertain information stays distinct from unavailability. Nearby checks require an explicit action and do not change the chosen store. See the [local entry file](prototype/index.html) and instructions above.
