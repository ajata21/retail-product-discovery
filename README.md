# retail-product-discovery
Independent product management case study examining sporting goods e-commerce UX and product discovery

Research update — October 20, 2026: The [completed online research pilot](research/online-research-pilot.md) documents reported public-feedback screening and a targeted Academy pickup check, with attached screenshot evidence. Candidate problems remain under review; no final problem, PRD, or solution has been selected. Pilot screening does not change the legacy accepted-feedback totals.

Follow-up — October 20, 2026: The [fixed three-product Academy website check](research/academy-website-followup.md) informs a [provisional problem brief](product/problem-brief.md) focused on pictured-variant, size, and selected-store pickup clarity. This is a desktop-web portfolio scope decision, not validated customer priority; no PRD or prototype has been created.

Draft product direction — October 20, 2026: [Exploratory PRD](product/prd.md) proposes exact-variant pickup information on desktop product cards. This independent portfolio concept is not an official retailer initiative or a validated solution; no prototype has been implemented.

Local prototype — October 20, 2026: Open [prototype/index.html](prototype/index.html) in Chrome by double-clicking it (or Chrome → Ctrl+O). No installation or server is needed. See [prototype instructions, scenarios, and verification](prototype/README.md). All availability is simulated; no ordering or live inventory connection.

Design revision — October 21, 2026: The [revised PRD](product/prd.md) proposes qualifying pictured variants and confirmed selected-store pickup matching, while respecting explicit color choices and distinguishing uncertain results. The existing prototype still implements the earlier direction and has not been updated to these revised requirements; this is a design decision, not a validated improvement.

Prototype implementation update — October 21, 2026: The [local prototype](prototype/index.html) now implements revised qualifying-variant matching, explicit Any color preferences, and separate uncertain/non-matching results. Its default qualifying-color scenario is visibly labeled invented; historical mode preserves unknown combinations. See [scenarios, revised checks, screenshots and limitations](prototype/README.md). Open index.html directly in Chrome; no server or installation is needed. This supersedes the earlier same-day “not updated” prototype status; no customer improvement has been validated.
